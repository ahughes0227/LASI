# Experiment Plan Output Contract

`experiment_plan.md` contains:

- Project ID
- Linked dataset version ID
- Testable hypothesis and experiment type
- Planned tool runs with run IDs, inputs, parameters, and model specification when applicable
- Metrics, expected signal, and expected outcome
- Order and dependencies
- Estimated cost and timeline
- Explicit success and failure criteria
- Stop conditions
- Execution backend and expected artifacts
- `decision_record_required`
- Provenance
