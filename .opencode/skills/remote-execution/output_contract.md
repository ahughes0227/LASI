# Remote Run Output Contract

`remote_run_record.md` contains:

- Project ID, experiment ID, plan ID, and tool-run ID
- Authorizing decision ID
- Host profile and remote workspace
- Exact command and environment setup
- Start and end times
- Exit code and run status
- Stdout, stderr, and run-log URIs
- Retrieved and missing artifact URIs
- Cleanup status
- Provenance
- Structured failure reason and retry guidance when applicable
