# Dataset Intake

Produce `dataset_manifest.md` for a canonical versioned asset. Capture project and dataset version IDs, source description, file checksums, privacy tags, owner contact, and provenance from the raw export or access instructions.

Read `AGENTS.md`, `_core/glossary.md`, `_core/authority_boundaries.md`, and `_templates/dataset_manifest/dataset_manifest_template.md`. Dataset versions, label changes, benchmark changes, privacy changes, and authoritative storage changes require the appropriate decision or proposal.

Follow `checklist.md`, validate the result against `output_contract.md`, and use only synthetic or redacted material from `examples/` as guidance.
