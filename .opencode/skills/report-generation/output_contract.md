# Static Report Output Contract

The immutable static HTML report contains:

- Header and executive summary
- Project and dataset version identity
- Dataset characterization
- Experiment and model comparisons
- Performance-gap diagnosis
- Learning-curve, error, and cluster analysis
- Scientist review and evidence
- Decision records and authorized next actions
- Knowledge context
- Project outcome status
- Provenance and artifact URIs
- Explicit status and reason for every missing, blocked, failed, partial, or deferred section

Every section must include source records and source artifacts when available.
