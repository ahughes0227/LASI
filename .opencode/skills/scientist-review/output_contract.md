# Scientist Review Output Contract

`scientist_review.md` contains:

- Review, project, experiment, and diagnostic-packet identifiers
- Provider profile and model identity
- Primary diagnosis and confidence
- Supporting and counter-evidence
- Alternative hypotheses
- One primary recommendation and ranked secondary recommendations
- Expected value, estimated cost, uncertainty, and review flags
- Stop and human-review recommendations
- Evidence and knowledge references
- Separate provenance source records and source artifacts
- Raw provider-response artifact reference

The review must not authorize changes.
