Skill: Experiment Planning
==========================

Purpose
-------

Translate dataset issues into an ordered experiment plan with success criteria and required inputs.

When to use
-----------

After dataset characterization and before running experiments.

Required inputs
---------------

- `dataset_characterization.md`
- Project objectives and evaluation metrics

Required outputs
----------------

- `experiment_plan.md` saved under project artifacts.

Files to read first
-------------------

- _templates/experiment_plan/experiment_plan_template.md

Forbidden actions
-----------------

- Do not run experiments or execute remote runs; produce the plan only.

Completion criteria
-------------------

- Plan includes experiments, metrics, estimated cost, and success criteria for each step.
