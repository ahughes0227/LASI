# Limitations

- Kaggle's public score is the only available external feedback; Titanic test
  labels remain inaccessible to LASI.
- The 0.8380 held-out score did not translate into a score above the existing
  LASI best public score of 0.78229.
- This branch tested only a logistic-regression family and one reviewed feature
  composition. A further attempt needs a new approved hypothesis and component
  specification, not routine tuning.
