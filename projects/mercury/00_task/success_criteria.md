# Success Criteria

## Research success

- A locally supplied challenge package completes immutable intake, hashing, format validation, leakage audit, and time-series characterization.
- Each approved experiment uses a fixed chronological validation policy and produces traceable metrics, predictions, configuration, and logs.
- Any prediction artifact validates against the locally verified submission schema.

## Challenge success

- The strongest permitted, reproducible submission is selected only from directly comparable, approved evidence.
- A Kaggle score or rank is recorded as an external evaluation outcome when and only when the user submits through an authorized account.

## Explicit limits

- `winning_score`: not guaranteed.
- `competition_status`, `deadline`, `submission_limit`, and rules: not locally verified.
- No hidden-label access, answer lookup, web access after intake, external data, remote execution, or external provider use is permitted unless separately governed.
