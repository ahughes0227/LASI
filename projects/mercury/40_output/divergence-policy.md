# Divergence-First Research Policy

Under Mercury's standing authorization, when a controlled path fails to improve sufficiently or saturates, LASI must not keep tuning that path blindly. It must:

1. launch bounded research for materially different, legitimate solution families;
2. compare their assumptions, information requirements, leakage risks, and expected value against current evidence;
3. requisition a new governed component when no approved component can test the best divergent path;
4. validate the component on synthetic fixtures before challenge execution;
5. run the highest-information, directly comparable candidate branch; and
6. submit only validated candidates with a plausible evidence-backed improvement path.

Current trigger: the recursive seasonal improvement establishes a better reference but remains a narrow univariate forecasting family. It does not explain remaining error or establish a plateau across divergent families.

## Artifact contract

- **READ:** current local and Kaggle evidence, public challenge research, component registry, and policy constraints.
- **DO:** seek divergent legitimate methods and draft component proposals; do not use external datasets or hidden labels.
- **WRITE:** source-backed research notes, ranked hypotheses, component requisitions, acceptance evidence, plans, and decisions.
