Step: 07 Decision Review
========================

Purpose
-------

Record human decisions that permit or block next actions.

Inputs
------

- `scientist_review.md` and supporting artifacts

Actions
-------

1. Run `decision_review` checklist.
2. Save `decision_record.md` with scope and rationale.

Skill
-----

decision_review

Expected output
---------------

- `decision_record.md`

Stop / Escalation
-----------------

- If decision is unclear, route to appropriate approver and pause the workflow.

Handoff
-------

Pass decision to `08_generate_report` and to any downstream execution tasks.
