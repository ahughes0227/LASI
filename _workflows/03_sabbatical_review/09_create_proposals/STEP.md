# Step 09 — Create Proposals

Purpose
: Draft knowledge proposals for facts, policies, or tool updates; these are not approved until explicitly recorded.

Actions
- Draft `knowledge_proposal.md` files using `_templates/knowledge_proposal/knowledge_proposal_template.md`.

Skill
- knowledge-curation

Expected output
- `projects/<id>/artifacts/knowledge_proposals/*.md`

Stop / Escalation
- Do not apply proposals to `knowledge/` until a decision record approves the change.

Handoff
- Store proposals in project artifacts and notify recommended approvers.
