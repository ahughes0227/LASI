# Step 01 — Review Update Proposal

Purpose
: Read the update proposal and change log; map claimed fixes to measurable signals.

Inputs
- Update proposal, change log, parent dataset manifest

Expected output
- Update checklist and risk assessment saved to `projects/<id>/inputs/update_review.md`

Actions
- Extract claimed fixes and map to benchmarks or metrics.
- Note required data access, privacy implications, and compute needs.

Stop / Escalation
- Missing manifests or access to parent/child datasets.

Skill
- `dataset-intake`, `dataset-characterization`
